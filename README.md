# Динамический массив на языке C (Лабораторная работа)

Проект представляет собой модульную реализацию динамического массива с поддержкой полиморфизма. Система позволяет работать с различными типами данных (вещественные числа double и строки char*), используя унифицированный интерфейс, и включает в себя инструменты для автоматического тестирования и управления памятью.

## Особенности реализации
* **Модульная архитектура:** Проект разделен на логические слои (описание типов, логика массива, тесты, интерфейс), что обеспечивает чистоту кода и легкую масштабируемость.
* **Полиморфизм:** Реализован с помощью структуры-«паспорта» (`TypeInf`), что позволяет функциям (сортировка, маппинг, фильтрация) работать с любыми типами данных через `void*`.
* **Управление памятью:** Использование `malloc`, `realloc` и `free` с защитой от ошибок и утечек.
* **Автоматизированное тестирование:** Встроена система юнит-тестов с использованием `assert`, позволяющая быстро проверять корректность работы алгоритмов.

## Структура проекта
* `main.c` — точка входа и диспетчер меню.
* `dynamic_array.c / .h` — ядро проекта, реализация структуры динамического массива.
* `types.c / .h` — описание конкретных типов данных (double, char*) и их специфичных функций (компараторы, вывод, трансформации).
* `tests.c / .h` — модуль автоматического тестирования логики.
* `Makefile` — скрипт для автоматизации сборки проекта.

## Режимы работы
Программа поддерживает два основных режима:

Автоматические тесты: Изолированный запуск набора проверок (добавление, сортировка, маппинг, фильтрация и склеивание) для обоих типов данных с целью подтверждения работоспособности всех функций.

Ручной режим: Полноценный интерактивный режим, где пользователь может выбрать тип данных, самостоятельно наполнить массив, выполнить сортировку по любому направлению, применить функции Map/Where и посмотреть результат в консоли.
